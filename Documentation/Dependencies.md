# MDEdit Dependency List
> [!IMPORTANT]
> The dependencies given below are as of 21st November 2026 after migrating to `PySide6`
- `Python 3.14.0`
- `Pyinstaller`
- `PySide6`
- `Markdown`



---
## Notes

- InnoSetup is required to build the setup file.
- Project must be bundled using <kbd>--onedir</kbd> flag on pyinstaller.  
- MDEdit Themes will be built separately.
